## What to build

A cross-feature visual audit to verify all polish criteria are met across the
full assembled app. Fix any gaps found — no new features, only visual
correctness against the acceptance criteria defined in earlier stories.

## Acceptance criteria

- [ ] Completed tasks render with strikethrough and muted styling (grey text or reduced opacity)
- [ ] The active filter button is visually distinct from inactive ones at a glance
- [ ] Input and submit button are clearly grouped and easy to reach on both mobile and desktop
- [ ] No layout shifts or unstyled flashes on initial page load (check with browser DevTools)
